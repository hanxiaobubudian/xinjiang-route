采用原私人网站已发布第 2 版的完整源码，保留设计、数据与交互。

## 本地查看

需要 Node.js 16 或更新版本，无需安装依赖。

```sh
npm run dev
```

打开 http://127.0.0.1:5173/#overview 。此命令仅监听本机。

## 检查与构建

```sh
npm run check
npm run build
```

构建后 `dist/` 中的三个文件就是可部署的静态网站文件。修改 `src/` 后重新构建。没有数据库、API 密钥或服务端依赖。

- `src/index.html`：原版页面结构与路线示意图。
- `src/styles.css`：原版深绿、橙色主题和移动端布局。
- `src/app.js`：29 天行程、账本、交互地图、区域和天数筛选、详情抽屉。
- `tests/smoke.mjs`：结构与账本检查。
- `tests/browser.mjs`：可选浏览器检查，需要 Playwright 和 Chromium；默认访问本机 5173 端口。
